# Repo Tracking

这个目录记录当前仓库的项目进展，不是运行时的机器人/会话 tracking。

深度设计与 API 说明仍放在 `docs/`。这里只保留可扫描的进度摘要，方便下次会话快速接手。

## 文件

- `overview.md`: 长期背景、目标、里程碑
- `current.md`: 当前快照（先读这个）
- `decisions.md`: 重要决策
- `daily/YYYY-MM-DD.md`: 每天一篇日志

## 开始工作

1. 先读 `current.md`
2. 再读 `overview.md`
3. 需要时再看最近几篇 daily

## 结束工作

1. 追加今天的 daily
2. 更新 `current.md`
3. 需要时记录决策
4. 仅在目标/阶段变化时更新 `overview.md`
